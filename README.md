 Simulación de Temporizador Digital

 Descripción

Este ejercicio consiste en crear una clase en Java que represente un temporizador digital. Permite controlar los minutos y segundos restantes y actualizar el tiempo cuando pasan determinados segundos.

Funcionamiento

* Inicializar el temporizador con minutos y segundos.
* Validar que los minutos no sean negativos y que los segundos estén entre 0 y 59.
* Avanzar el tiempo una cantidad determinada de segundos.
* Actualizar correctamente los minutos y segundos cuando el tiempo cambia.
* Mostrar el estado final del temporizador por consola.

 Conceptos utilizados

* Clases y objetos.
* Encapsulamiento.
* Constructores.
* Métodos.
* Validaciones.
* Operaciones matemáticas.

 Ejemplo

Se crea un temporizador con un tiempo inicial, se simula el paso de varios segundos y se muestra el tiempo actualizado por consola, manteniendo la relación correcta entre minutos y segundos.
